Funcionalidades

¿Por qué PilotQA AI?

Deja de perder horas manteniendo selectores rotos. Describe lo que quieres probar en español y la IA se encarga del resto.

📝

Pruebas en Lenguaje Natural

Escribe lo que deseas probar en español o inglés. Cero XPath, cero selectores CSS frágiles. La IA interpreta y ejecuta.

🤖

Agente de IA Flexible

Elige el agente de IA que mejor se adapte a tu flujo de trabajo. Configuración en una línea, sin complicaciones.

🎯

Resaltado Visual de Elementos

Durante la ejecución, cada elemento con el que se interactúa se resalta en el navegador en tiempo real. Depurar nunca fue tan fácil.

🔄

Reintento Inteligente

¿Falla por tiempos? PilotQA AI reintenta automáticamente con backoff inteligente, eliminando la inestabilidad (flakiness).

🧩

Agnóstico de Framework

Funciona con cualquier test runner: node:test, Jest, Vitest. Driver de navegador propio, sin depender de runtime externo.

⚡

CLI Propio

Ejecuta con npx pilotqa test. Configura mediante pilotqa.config.ts, workers paralelos, modo headless y mucho más.

Cómo funciona

3 pasos para automatizar

1

Instala y configura

Clona el repositorio, configura tu clave de API en un archivo .env. Listo en minutos.

2

Escribe en lenguaje natural

Describe el flujo que quieres probar como si lo estuvieras explicando a una persona. Sin selectores, sin esperas manuales.

3

Ejecuta y monitorea

Ejecuta con npx pilotqa test. Observa cómo el navegador ejecuta cada paso con resaltado visual e informe automático.
