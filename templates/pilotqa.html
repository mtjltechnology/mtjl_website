Por que PilotQA AI?

Chega de perder horas mantendo seletores quebrados. Descreva o que quer testar em português e a IA cuida do resto.

📝

Testes em Linguagem Natural

Escreva o que deseja testar em português ou inglês. Zero XPath, zero CSS selectors frágeis. A IA interpreta e executa.

🤖

Agente de IA Flexível

Escolha o agente de IA que melhor se encaixa no seu fluxo. Configuração em uma linha, sem complicações.

🎯

Highlight Visual de Elementos

Durante a execução, cada elemento interagido é destacado no browser em tempo real. Depuração nunca foi tão fácil.

🔄

Retry Inteligente

Falha por timing? PilotQA AI tenta novamente automaticamente com backoff inteligente, eliminando flakiness.

🧩

Framework Agnóstico

Funciona com qualquer test runner: node:test, Jest, Vitest. Arquitetura preparada para Playwright, Cypress e Puppeteer.

⚡

CLI Próprio

Execute com npx pilotqa test. Config via pilotqa.config.ts, workers paralelos, modo headless e muito mais.

Como funciona

3 passos para automatizar

1

Instale e configure

Clone o repositório, configure sua chave de API em um arquivo .env. Pronto em minutos.

2

Escreva em linguagem natural

Descreva o fluxo que quer testar como se estivesse explicando para uma pessoa. Sem selectors, sem waits manuais.

3

Execute e monitore

Rode com npx pilotqa test. Veja o browser executar cada passo com highlight visual e relatório automático.
